# IBM Bob Usage

## Project
AI-Powered Sustainable Farming Advisor

## Use of IBM Bob
IBM Bob was used as an AI-assisted software development environment during the development of this project.

It supported:
- Project setup and organization
- Code development and refinement
- Reviewing and improving application code
- Assistance during the development workflow
- Organizing the Streamlit-based application

## AI Application
The final application uses a Random Forest Classification model trained on the Crop Recommendation Dataset.

The model uses:
- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Temperature
- Humidity
- Soil pH
- Rainfall

## Responsible AI
The application provides decision-support guidance only. Recommendations should be verified using soil tests, local conditions, and advice from qualified agricultural experts.

## Project Outcome
The completed prototype provides crop suitability recommendations and sustainable farming guidance related to water, fertilizer, soil, and environmental risk awareness.
